## Разборы — синхронизация с Claude

Пользователь отправляет из приложения заявки (щит из конструктора, вопрос, фото, прогресс, ошибку). Они приходят как GitHub issues с меткой `razbor` от `Slowmeow`; в теле — скрытый код `<!-- SHK1z.… -->` (JSON, deflate-raw, base64url). Заявки от других авторов не разбираем. Из версии в Claude заявки лежат в db артефакта, коллекция `inbox` (читать через ArtifactData), там же ответ можно положить в коллекцию `razbory`.

Когда пользователь пишет «проверь разборы»:

1. `node tools/claude.mjs inbox` — открытые заявки.
2. `node tools/claude.mjs show <номер>` — заявка целиком. Для щита сразу печатается расчёт конструктора (аппараты, кабели, проверки). Фото из заявки скачай и посмотри.
3. Напиши разбор в markdown (заголовки `**…**`, списки, `> [!TIP]`/`> [!WARNING]`, ссылки на экраны приложения вида `[урок про УЗО](#lesson.rcd)`). Пункты ПУЭ/СП 256 называй, только если уверен.
4. `node tools/claude.mjs reply <номер> --md разбор.md [--cfg щит.json --cfgname "…"] [--links '[["Урок","lesson.rcd"]]']` — добавит разбор в `razbory/index.json`, закоммитит, запушит, ответит в issue и закроет его. Исправленный щит (`--cfg`) пользователь откроет кнопкой «Открыть щит в конструкторе».
5. Через 1–3 минуты (сборка Pages) разбор появится в приложении в разделе «Разборы», за прочтение — XP.

Если пользователь вставил в чат код `SHK1z.…`: `node tools/claude.mjs decode <код>`, затем `node tools/claude.mjs add --title "…" --md файл.md --type …` и `git push`.

## Сборка и проверка

- `python tools/build.py` — собирает `index.html` из `app.html` и обновляет версию офлайн-кэша в `sw.js`. Запускать перед каждым коммитом с изменениями кода.
- `node tools/test-engine.cjs 1000` — строгая проверка конструктора на проектах, щитах с фото и случайных щитах.
- `node tools/test-content.cjs` — проверка содержимого (загружает скрипты в порядке `app.html`; уроки `v2: true` проверяются по новому шаблону).
- Колода Anki: `node tools/export-cards.cjs` → `python tools/build_anki.py` (нужен `genanki`) → `python tools/check_anki.py` (нужен пакет `anki`: импортирует колоду настоящим движком Anki). Результат — `anki/shkola-shchitovika.apkg`, ссылка на него есть в каждом уроке. Имена подколод задаёт `S.anki.deckOf` в `js/program.js`; id типов записей в `build_anki.py` не менять.
- Прогресс пользователя хранится только в его браузере (`localStorage`, ключ `shk:v1`); в репозиторий он не попадает, пока пользователь сам не отправит заявку «Мой прогресс».
